# Graphite Theme

Простое Chrome-расширение, которое заменяет ослепительно светлый фон сайтов на спокойный графитовый цвет.

Это не полноценная замена встроенной тёмной теме, но быстрое решение для тех, кто любит работать по ночам и не хочет лишний раз напрягать глаза.

## Возможности

- Графитовый фон вместо светлого интерфейса.
- Светлый текст для комфортного чтения.
- Включение и выключение темы одним переключателем.
- Сохранение выбранного состояния.

## Структура проекта

```text
graphite-theme/
├── manifest.json  # Extension configuration
├── popup.html      # Popup markup
├── popup.css       # Popup styles
├── popup.js        # Toggle logic
└── content.js      # Website theme styles
```

**Стек:** HTML, CSS, JavaScript, Chrome Extensions Manifest V3.

## Установка в Google Chrome

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Откройте Chrome и перейдите по адресу `chrome://extensions/`.
3. Включите **Режим разработчика (Developer mode)** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение (Load unpacked)**.
5. Выберите папку проекта, содержащую `manifest.json`.

Готово! Расширение установлено.

## Использование

1. Нажмите на значок расширений в панели Chrome.
2. Откройте **Graphite Theme**.
3. Включите переключатель, чтобы применить графитовую тему.
4. Выключите его, чтобы вернуть оригинальные цвета сайта.

Настройка сохраняется автоматически.

## Ограничения

Расширение принудительно изменяет CSS-стили страниц, поэтому на некоторых сайтах отдельные элементы могут отображаться некорректно.
